\section{Related Work}\label{sec:related_work}

\subsection{Retrieval-Augmented Generation in Clinical QA}
RAG grounds generation in an external corpus instead of relying on parametric memory alone \citep{lewis2020retrieval}. Biomedical systems often start with dense retrievers over PubMed or guideline text \citep{lee2020biobert,huang2019clinicalbert}. Dense search handles paraphrase well but can miss exact drug names, serotypes, and gene markers that sparse BM25 retrieval still picks up. Hybrid pipelines that fuse both channels are now common in general-domain surveys of RAG \citep{gao2023retrieval}.

Retrieval quality alone does not guarantee safe answers. Med-PaLM \citep{singhal2023large}, GPT-4 on medical exams \citep{nori2023capabilities}, and other clinical LLMs can still produce claims that are hard to trace to a specific source span. Benchmark suites such as BioASQ \citep{tsatsaronis2015overview} and MedRAG \citep{xiong2024medrag} measure grounding, but most deployments still lack a runtime check that every sentence is attributable before release.

\subsection{Hallucination Mitigation and Attribution}
Mitigation strategies range from post-hoc hallucination detectors \citep{manakul2023selfcheckgpt} to training models that emit explicit reflection tokens about retrieval need and support \citep{asai2024selfrag}. Attribution frameworks such as AIS ask whether each generated statement is supported by identified sources \citep{rashkin2023measuring}. Self-RAG and similar methods require model changes or fine-tuning, which is costly when the production stack is built on proprietary API models.

\subsection{Stateful Orchestration and Self-Correction Loops}
Agent-style orchestration can rerun generation when a check fails. LangGraph expresses such workflows as cyclic graphs with explicit validator nodes \citep{langgraph2024}. X-CDS uses this pattern with a lightweight rule: cited sentences must share sufficient token overlap with the referenced chunk. The goal is not to train a new verifier, but to add a deterministic gate that API-hosted models can pass through without retraining.

\subsection{Positioning of X-CDS}
Compared with Self-RAG \citep{asai2024selfrag}, X-CDS does not learn when to retrieve or critique; it always retrieves and then validates citations. Compared with LLM-as-judge detectors \citep{manakul2023selfcheckgpt}, overlap checking is cheaper and fully reproducible, at the cost of sensitivity to paraphrase. We evaluate that trade-off on arbovirus-focused clinical scenarios in \cref{sec:results}.
